# 🐳 Whale Collector

고래상어와 함께 바다를 유영하며  
귀여운 바다 친구들을 수집하는  
**PC 웹 기반 2.5D 캐주얼 힐링 게임**입니다.

전투 없이  
성장과 수집, 비주얼 변화에 집중합니다.

---

## 🎮 게임 컨셉

- 플레이어는 **고래상어**
- 바다를 헤엄치며 친구들을 수집
- 수집 = 공격력 ❌  
  → **외형 변화 / 파티클 / 분위기 변화**

### 수집 예시
- 🐟 작은 물고기 → 꼬리 주변을 맴도는 장식
- 🪼 해파리 → 밤 스테이지에서 은은한 조명
- 🐳 아기 고래상어 → 따라다니는 펫

---

## 🧠 핵심 특징

- 2D / 2.5D 비주얼 중심 설계
- PC 웹 기반 (모바일 아님)
- 마우스 중심의 느긋한 조작
- 오래 켜두기 좋은 힐링 게임
- 데이터(JSON) 기반 성장/행동 시스템
